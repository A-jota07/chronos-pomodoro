# Chronos — Pomodoro Timer ⏱️

**Chronos** é um aplicativo simples de cronômetro baseado na técnica
**Pomodoro**, desenvolvido com **React**, **TypeScript** e **Vite**. O objetivo
do projeto é ajudar a aumentar a produtividade aplicando ciclos de trabalho
focado e intervalos curtos.

---

## 🧭 O que é a técnica Pomodoro?

A técnica Pomodoro é um método de gestão de tempo que divide o trabalho em
blocos (geralmente 25 minutos) chamados _Pomodoros_, separados por intervalos
curtos (5 minutos). Após completar alguns pomodoros (por exemplo, 4),
recomenda-se um descanso mais longo (15–30 minutos).

---

## ✨ Funcionalidades

-   Cronômetro de contagem regressiva para sessões de trabalho (Pomodoro) e
    intervalos.
-   Permite configurar durações básicas (tempo de trabalho e de descanso).
-   Visualização do ciclo atual.
-   Interface leve e responsiva construída com CSS Modules.

---

## 🚀 Instalação e execução

Pré-requisitos: **Node.js** e um gerenciador de pacotes (npm, yarn ou pnpm).

Passos:

1. Instale as dependências:

```bash
npm install
# ou
# yarn
# pnpm install
```

2. Execute em modo de desenvolvimento:

```bash
npm run dev
```

3. Para build de produção:

```bash
npm run build
npm run preview
```

4. Rodar o linter:

```bash
npm run lint
```

---

## 🧩 Como usar

1. Abra o app no navegador (normalmente em `http://localhost:5173`).
2. Configure a duração do Pomodoro e do intervalo se desejar.
3. Inicie o cronômetro para começar a sessão de foco.
4. Use pausar, reiniciar ou acompanhar os ciclos conforme necessário.

> Dica: o padrão da técnica é 25 minutos de trabalho e 5 minutos de descanso —
> ajuste conforme sua necessidade.
